💡 Core Principles

Principle 1: Executability (doc 14)

NOT: "Assume code will work"
BUT: "Verify everything works in REAL environment"

Every assertion, endpoint, selector, value, precondition
must be VERIFIED IN REAL ENVIRONMENT before code.

Principle 2: Assertion Quality (doc 16)

Rule 1: Every assertion must be able to FAIL
✅ expect(status).toBe('DRAFT')
❌ expect(true).toBe(true)

Rule 2: Every error must PROPAGATE
✅ throw new Error(`Failed: ${msg}`)
❌ .catch(() => false)

Rule 3: Every value from TC (not code)
✅ From TC Then clause
❌ From code assumption

Principle 3: Detailed Failure Diagnosis (doc 15)

When test FAILS at runtime: 1. Identify LAYER (PRE, FACTORY, USECASE, Layer3, SPEC) 2. Root cause analysis 3. Evidence (screenshot, video, logs, stack trace) 4. Decision tree (fix code? re-ground? escalate?) NOT: "Test failed" BUT: "SPEC assertion fail at line 26..."

Principle 4: Centralized Traceability (doc 17)

NOT: Comments scattered in code
BUT: AUTOMATION-CHECKLIST-<TC-ID>.md

✅ Explicit: TC clause → assertion mapping
✅ Self-reviewed: engineer verify match
✅ Centralized: one place to see full coverage
✅ Plus: Code comments as backup

3-Layer Review System

📊 Workflow Phases: Before vs After

BEFORE (Downstream Detection)

Code Written
  ↓
Test Run
  ↓
PR Review (FIRST TIME detect: tautology, swallowed error, hardcoded)
  ↓ REQUEST_CHANGES: Rework needed
Fix Needed
  ↓
Re-test
  ↓
EXPENSIVE CYCLE

AFTER (Upstream Prevention + Detailed Diagnosis)

Phase 0: INTAKE
  └─ Ask: environment, test data, account

Phase 1: GROUNDING
  └─ Verify: selector exist, endpoint respond, value accessible

Phase 2: DESIGN
  └─ Design: assertion template, error handling plan

Phase 3: MAPPING
  └─ Map: Layer responsibility

Phase 4: IMPLEMENT
  └─ Prevent: tautology, swallowed error, hardcoded
  └─ Create: AUTOMATION-CHECKLIST-<TC-ID>.md

Phase 5: VERIFY
  └─ Run: test PASSED
  └─ IF fail: detailed diagnosis (layer, root cause, decision)

Phase 6: PRE-PUSH
  └─ Verify: traceability checklist

PR REVIEW
  └─ Confirm: quality at source, rarely find new issue

RESULT: Quality upstream, clear diagnosis if fail
